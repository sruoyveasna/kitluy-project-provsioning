# Shared-service documentation family

Each service README under `services/` is its boundary document (runtime
boundary, ownership, contracts, evidence status). Deep specifications (APIs,
events, jobs, permissions, observability, retries, failure modes, degraded
behavior, recovery, tests, deployment) are authored here per service when it
leaves SCAFFOLDED. Registered services: File Service, Notification Service,
Integration Hub, Connector Runtime, AI Gateway, MCP Server, RAG Indexer,
Reporting and Export Service, Device Release and Update Service, Sync Service,
Configuration Projection, Device Registry, Provisioning, API Gateway, and the
four governed APIs plus kitluy-hub-agent.
