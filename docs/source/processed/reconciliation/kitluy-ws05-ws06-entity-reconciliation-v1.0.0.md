Publication states used are EXACTLY the canonical KBR-CFG §4 machine (`DRAFT`, `VALIDATION_FAILED`, `VALIDATED`, `APPROVAL_REQUIRED`, `APPROVED`, `REJECTED`, `EXPIRED`, `PUBLISHING`, `PUBLISHED`, `ACKNOWLEDGED`, `ACTIVE`, `PARTIAL_FAILURE`, `FAILED`, `SUPERSEDED`, `ROLLED_BACK`; target results `STAGED`/`ACTIVE`/`FAILED`/`ROLLED_BACK` per KBR-CFG-005/007). The distinct lifecycle facts map: authored/snapshot → `configuration_versions`; approved → `approval_request_id` link to `kitluy_auth.approval_requests`; publication → `configuration_publications`; delivered/acknowledged → `configuration_acknowledgements`; activated/failed/rollback → `configuration_targets` and rollback-kind publications.
