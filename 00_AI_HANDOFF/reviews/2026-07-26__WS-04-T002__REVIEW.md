## 5. Decision rationale

Structure, naming, counts, policy model, grants topology, four-eyes constraints and honesty labeling all check out exactly against the RLS specification — verified by independent counting, not by trusting the file's manifest. The single blocking defect is real and total: the append-only guard, the stated defense-in-depth for every evidence table this cycle exists to protect, never rejects anything because `current_user` inside a SECURITY DEFINER trigger is the definer. The authored KLSEC-036 test would expose it on first execution; static review must therefore block now, since execution is BLOCKED (BLK-002) and nothing downstream would catch it before data exists. Fix is a one-line change (drop SECURITY DEFINER) plus the RV-202 grant narrowing; everything else in these two files is approvable as-is.
