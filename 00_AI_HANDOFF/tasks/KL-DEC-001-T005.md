# KL-DEC-001-T005 — Align API error registry and package

| Field                 | Value                                                                                                                                                                                                                                                                                   |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Objective             | Align `packages/api-errors` to the canonical API Error Code Registry and add the four approved codes with their approved semantics                                                                                                                                                      |
| Authority sources     | KLD-2026-07-26-002 Group 5 (APPROVED WITH ADDITIONS); `docs/source/api-contracts/kitluy-api-error-code-registry-v1.0.0.md`                                                                                                                                                              |
| Files owned           | `packages/api-errors/**`; consumers referencing retired generic codes                                                                                                                                                                                                                   |
| Conflicts resolved    | KLREC-2026-07-26-010 (error-code naming)                                                                                                                                                                                                                                                |
| Added codes           | `INTERNAL_ERROR` (500, retryable with the same idempotency key); `SCALE_UNSTABLE` (422, retryable once a stable reading exists); `GARMENT_COUNT_MISMATCH` (409, NOT safe for blind automatic replay); `HUB_READ_ONLY` (503, retryable only after Hub write health recovers)             |
| Prohibited scope      | No divergent hand-maintained list where the registry is canonical; retire generic `CONFLICT` and production `EDGE_*` codes; `PAYMENT_PENDING` must remain HTTP 202 non-terminal and must never be converted into a paid/terminal state; no fabricated success on INTERNAL_ERROR         |
| Acceptance criteria   | Canonical names, HTTP statuses, retryability, message keys and safe operator actions match the registry; the four codes exist with approved semantics; rejected codes absent; `PAYMENT_PENDING` proven non-terminal                                                                     |
| Tests                 | Code/status/retryability tables; idempotent retry behavior; rejected generic `CONFLICT`; rejected `EDGE_*`; `PAYMENT_PENDING` 202 non-terminal and never paid; `HUB_READ_ONLY` fail-closed; `GARMENT_COUNT_MISMATCH` blocks Ready and pickup completion; `SCALE_UNSTABLE` bounded retry |
| Evidence requirements | Error-registry delta table; test output                                                                                                                                                                                                                                                 |
| Rollback              | `git revert`                                                                                                                                                                                                                                                                            |
| Status ceiling        | Contract alignment IMPLEMENTED-IN-DEV                                                                                                                                                                                                                                                   |
